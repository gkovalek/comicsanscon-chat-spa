# Assets de personajes

Colocá acá las imágenes reales de cada personaje (PNG con fondo transparente recomendado) con estos
nombres exactos — el código ya las referencia por esta ruta:

- `yogi.png` — Oso Yogui
- `scooby.png` — Scooby-Doo
- `bugs.png` — Bugs Bunny

Mientras no estén, la interfaz muestra una figura de reemplazo hecha en CSS (un "blob" con el color del
personaje) en el mismo lugar, así el layout no se rompe. Al agregar los archivos con estos nombres, la
imagen real reemplaza automáticamente al placeholder sin tocar código.
